Master's Thesis — Anomaly Detection in Robotic Unscrewing

KU Leuven · Ongoing

For my thesis, I'm building a machine learning pipeline that detects anomalies from sensor data while a robot performs an unscrewing task on hard drives, using unsupervised methods. The goal is to catch irregularities in the process from sensor signals alone, without needing labeled failure data.

This project is currently under embargo, so I can't share methodology, datasets, or experimental setup details yet, but I'm happy to talk about it in more depth in person.
